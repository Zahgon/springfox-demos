# boot-swagger
An application with swagger 1.2, 2.0 and 3.0 api documentation enabled
 - Demonstrates using swagger groups 
 - Demonstrates manual configuration (explicit dockets rather than auto configuration)

```
go run ./boot-swagger
```

## Paths
- All Swagger Resources(groups) `http://localhost:8080/springfox/swagger-resources`
- Swagger UI endpoint: `http://localhost:8080/springfox/swagger-ui/index.html`
